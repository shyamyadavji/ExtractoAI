# 📑 ExtractoAI v2.5 | Enterprise Document Intelligence
**Live Site:** [extractoai.online](https://extractoai.online)

ExtractoAI is a professional-grade Full-Stack AI platform designed to digitize complex, handwritten, and multilingual documents (Hindi/English) into structured Excel data.

### 🚀 Top Features
- **AI Engine:** Powered by **Gemini 3 Flash** for frontier-class multimodal reasoning.
- **Handwriting Support:** High-accuracy Devanagari (Hindi) and English script recognition.
- **Human-in-the-Loop:** Interactive data editor to verify AI extractions before saving.
- **Full-Stack Memory:** Real-time database integration with **Supabase (PostgreSQL)**.

### 🛠️ Tech Stack
- **Frontend:** Streamlit (Python)
- **AI Logic:** Google Generative AI SDK (2026 Stable)
- **Database:** Supabase Cloud
- **Hosting:** Streamlit Cloud + GitHub Pages (Custom Domain)
